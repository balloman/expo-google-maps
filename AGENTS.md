# Repository Instructions

- When creating a pull request, name its branch or JJ bookmark after the feature or change rather than a release version.
- Include an appropriate changeset in pull requests that affect a publishable package.
- Before opening a pull request, use as many or as few commits or revisions as appropriate. Once the pull request is open, prefer adding feedback-driven updates in new commits or revisions instead of rewriting existing ones, so reviewers can follow the sequence of changes.
